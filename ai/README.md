# Переносимая команда OA/ERP

Общие правила и роли не привязаны к модели. Источники:
`GLOBAL_INSTRUCTIONS.md`, `agents.json`, `agents/*.md`.
Файлы `.codex/agents/*.toml` и `.claude/agents/*.md` генерируются из них.

| ID | Ответственность | Codex | Claude Code |
| --- | --- | --- | --- |
| TL-01 | План, ownership, интеграция, приёмка | `tech_lead_project_manager` | `tech-lead-project-manager` |
| BE-01 | Сервисы, данные, API/events, backend | `backend_architect_developer` | `backend-architect-developer` |
| FE-01 | UI, API-интеграция, четыре языка, a11y | `frontend_developer` | `frontend-developer` |
| UX-01 | Сценарии и дизайн-handoff | `ui_ux_designer` | `ui-ux-designer` |
| CR-01 | Независимое ревью фактического diff | `senior_code_reviewer` | `senior-code-reviewer` |

## Codex

Открыть репозиторий в новой доверенной сессии Codex с поддержкой custom agents.
Корневой `AGENTS.md` направляет к общим правилам; имена существующих четырёх
ролей сохранены, добавлена роль руководителя. Пример запроса:

> Выполни роль TL-01. Прочитай AGENTS.md и ai/GLOBAL_INSTRUCTIONS.md.
> Разбери текущую задачу; контракт модулей/API передай backend_architect_developer,
> UI-handoff — ui_ux_designer, реализацию — frontend_developer,
> независимое ревью — senior_code_reviewer. Назначь ownership и worktrees.

У Codex-адаптеров не заданы модель, sandbox, автоматические разрешения или
несуществующие поля isolation. Модель и разрешения наследуются от среды.
Изоляцию worktrees/веток и передачу pending patch организует TL-01 явно.

## Claude Code

`CLAUDE.md` импортирует общие инструкции и `AGENTS.md`. Дополнительный
`frontend/CLAUDE.md` импортирует frontend/AGENTS.md с правилами установленного Next.
Роли лежат в `.claude/agents/` и содержат полный общий prompt и конкретную роль,
поэтому не зависят от того, передаст ли launcher контекст главного чата.
Проверить обнаружение в интерфейсе `/agents` в новой сессии. Явный запуск:

```bash
claude --agent tech-lead-project-manager
# либо конкретная роль:
claude --agent backend-architect-developer
```

Для Claude-ролей указан `isolation: worktree`. Фактический baseline такого
worktree нужно проверить через `pwd` и `git worktree list`: отдельные launcher/team
режимы могут не применять поле изоляции. Его исходный baseline также может браться из default branch, а не pending
изменений родителя. Передать актуальный patch и необходимые новые файлы явно.
Автокоммиты для этой передачи запрещены без пользовательского разрешения.

Reviewer имеет Read/Grep/Glob/Bash для чтения и проверок. Это не аппаратный
запрет записи: Bash способен менять файлы. Независимость reviewer задаётся
инструкцией и ownership; разрешения среды, изоляция и review остаются обязательны.
Никакого `bypassPermissions`, подключения аккаунтов или установки Claude здесь нет.

## Другие ассистенты и обычный Claude-чат

Передать/прикрепить `ai/GLOBAL_INSTRUCTIONS.md`, один файл роли и контекст задачи
(утверждённую часть ТЗ, ADR, контракты и нужный код). Например:

> Работай по ai/GLOBAL_INSTRUCTIONS.md и ai/agents/backend-architect.md как BE-01.
> Scope: [...]. Модуль-владелец: [... или нерешённый вопрос].
> Разрешённые файлы: [...]. Критерии приёмки: [...]. Baseline/worktree: [...].
> Сначала опиши план и API/event-контракт; не меняй чужие файлы/БД.

Markdown — переносимая инструкция, не исполняемый агент сам по себе. Если чат
не умеет читать файлы, запускать инструменты или создавать subagents, он не
сможет выполнить проверки/делегацию только благодаря этим документам. Он должен
сообщить ограничение и не выдавать подготовленный текст за выполненное действие.
Это также не установка агентов в Claude Desktop/Projects или сторонний сервис.

## Обновление

Требуется Python 3.11+ (стандартная библиотека, без зависимостей приложения):

```bash
python scripts/sync_ai_agents.py
python scripts/sync_ai_agents.py --check
```

Генератор проверяет уникальность ID/имён, локальность source paths и TOML
roundtrip. Все output paths проверяются до чтения и записи: ссылки и выход за
границы репозитория запрещены, в том числе при `--adopt-existing`. `--check` ничего не записывает и возвращает ненулевой код при drift.
Неизвестные рукописные файлы агентов не удаляются. Старые сгенерированные
адаптеры вне актуального каталога обнаруживаются как orphan: генерация и
`--check` завершаются ошибкой до рассмотренного вручную удаления/переноса.
Так переименование роли не оставляет незаметно активную старую политику. Рукописный адаптер в ожидаемом пути
не перезаписывается без явного `--adopt-existing`: этот флаг использован только
при согласованном переносе прежних четырёх конфигураций в общий источник.
Не применять его вслепую при будущих обновлениях.

## Архитектура текущего этапа

По последнему решению пользователя продолжаем ТЗ как модульный монолит:
существующий Django backend, общая ORM/БД и локальные транзакции сохраняются.
BE-01 согласует модульные границы и API; разработка функций не ждёт выделения
сервисов. Действует `docs/adr/0002-monolith-for-current-delivery.md`, который
заменяет прежнюю обязательную микросервисную политику ADR-0001.

Микросервисы — будущий отдельный этап. Его границы, контракты и миграция данных
потребуют нового решения; сейчас брокер, сеть между модулями, отдельные БД и
распределённые транзакции не вводятся без необходимости/утверждения.

После каждого завершённого этапа ведущий агент объясняет работу результата,
показывает фактически выполненные проверки и ждёт ответа пользователя перед
следующей задачей. Commit/push/публикация/deploy не разрешаются настройкой ролей.

## Проверка и ограничения

Синтаксис и синхронизация проверяются локально. Нативный запуск делегации с
моделью требует установленного клиента, доступа к аккаунту и поддерживаемой
версии. Наличие конфигурационного файла не доказывает, что клиент уже загрузил
его или что системные разрешения изменились. Claude CLI в текущей среде отсутствует.

Форматы сверены 31.10.2026 с первичными источниками:

- [OpenAI: custom subagents](https://learn.chatgpt.com/docs/agent-configuration/subagents)
- [Anthropic: subagent files, tools and worktree isolation](https://code.claude.com/docs/en/sub-agents)
- [Anthropic: CLAUDE.md imports](https://code.claude.com/docs/en/memory)

Локально проверены 31.10.2026: 10 адаптеров без drift; пять TOML roundtrip
и пять YAML-заголовков; read-only drift detection, отказ перезаписи ручного
файла до любых записей, явный adopt, duplicate-ID rejection и отказ
file/parent/dangling symlink во всех режимах. Нативная загрузка/делегация
с моделью не запускалась; установленный Codex CLI — 0.155.0.
